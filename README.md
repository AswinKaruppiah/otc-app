# Quotex Mobile 📱

A mobile application built with React Native for an OTC platform that allows users to manage INR and USDT transactions through a simple mobile experience.

This project was developed to explore mobile application development with React Native and bring an existing web experience to mobile.

## ✨ Features

- 👤 User onboarding
- 📝 Create and manage USDT orders
- 📄 Upload payment slips
- 💰 Manage in-app USDT wallet
- 🔄 Withdraw USDT to an external wallet

## 🛠️ Tech Stack

### Core
- React Native 0.81
- React 19
- Expo SDK 54
- Expo Router

### UI & Styling
- Tailwind CSS v4
- Uniwind
- HeroUI Native

### Architecture
- Layered Architecture
- Reusable and modular components

### Data & API
- Apollo GraphQL Client
- GraphQL
- TronGrid Blockchain API

## 🏗️ Architecture

The application follows a layered architecture to keep the codebase organized, maintainable, and scalable.

- **Presentation** - Screens, UI components, navigation, and user interactions
- **Business Logic** - Application logic and state handling
- **Data** - API communication, Apollo Client, caching, and external services
